Health360 – Healthcare Risk & Disease Analytics

Overview

Health360 is a Tableau dashboard project designed to explore healthcare data, disease patterns, and lifestyle-related risk indicators.

Dashboard Features

* Patient distribution by age group
* Glucose levels across age groups
* Exercise-level distribution
* Health risk score analysis
* Heart disease rate by BMI
* Diabetes and heart disease indicators
* Key performance indicators (KPIs)

Tools Used

* Tableau Public / Tableau Desktop
* Data visualization and exploratory analytics

How to View

Download the Tableau packaged workbook (.twbx) from this repository and open it in a compatible Tableau application.
